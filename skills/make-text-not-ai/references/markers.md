# Marker catalogue

Compiled 2026-10 from WP:AISIGNS, ВП:ПРГЕН, corpus studies and practitioner lists (see
`sources.md`). Tier = the SKILL.md tier. Marker vocabulary rotates roughly yearly (2023 "delve",
2024 "showcasing", 2026 "dependable/quietly/matters"); the shape rules in SKILL.md §4 do not.

Format: marker → what to write instead. "cut" means delete the phrase and keep the sentence;
"drop" means the sentence usually goes too.

## English

### Delete tier

Chat residue and disclaimers
- Certainly! / Of course! / Absolutely! / Sure! Here's → cut
- Great question / Excellent point / You're absolutely right / Great catch → cut
- I hope this email finds you well / I hope you're doing well → drop
- I hope this helps / Let me know if / Feel free to / Would you like me to / Happy to help /
  Please don't hesitate to reach out / I look forward to continuing our journey → drop; one
  line of the genre's own courtesy ("Thanks", "Best regards") stays
- Here is a polished version / Here's a template you can copy → drop
- As an AI / as a language model / I don't have personal opinions → drop
- As of my last update / my knowledge cutoff / up to [date] → drop
- While specific details are limited / not widely documented / based on available information /
  in the provided sources → drop; it is a confession, not a fact
- It's important to remember that ... may vary / always consult / should be treated as X rather
  than Y / should not be confused with → drop unless the caveat is the author's real point
- [Your Name], [Company], [insert statistic], XX%, 2025-XX-XX → fill or drop

Debris
- oaicite, contentReference, turn0search0, citeturn0news0, [cite: 3], [1, 2], 【85†L26】,
  attached_file:1, grok-card, :::writing → delete
- utm_source=chatgpt.com / utm_source=openai / referrer=grok.com in URLs → strip the parameter
- literal **bold**, ### headings, `---` rules, [text](url) in a destination that does not render
  Markdown → plain text
- ✅ ❌ 🚀 💡 👉 as bullets; emoji before headings; → ≈ ⚠; box-drawing characters → plain
- curly “quotes” mixed with straight "quotes" in one text → one convention, the destination's

Meta-narration and scaffolding
- In this article / post / section, we will ... → drop
- Let's dive in / Let's break this down / Let's unpack / Let's explore / Without further ado → drop
- Key takeaways / TL;DR (uninvited) / In summary / In conclusion / To sum up / Overall /
  All in all / Ultimately / In essence / At its core / At the end of the day (as a recap opener)
  → drop the recap; as a plain connector between paragraphs they are density tier
- Conclusion section that restates → drop; end on the last concrete point
- The future looks bright / exciting times ahead / only time will tell / the possibilities are
  endless / as X continues to evolve → drop
- Despite these challenges, X continues to thrive / Future outlook / Challenges and opportunities
  as the closing formula → drop; keep any named challenge as a plain sentence

Grand openers
- In today's fast-paced world / In the ever-evolving landscape of / In the digital age /
  In an era of / Now more than ever / Since the dawn of → drop; start with the first fact
- X is a Y that ... (defining the topic to a reader who knows it) → drop

Importance puffery and significance tails
- plays a crucial / pivotal / vital / key role in (shaping) → "shapes", "decides", or the fact
- marks / represents a pivotal moment / a significant shift / a key turning point → the event
- a testament to / a reminder of / stands as a symbol of / embodies / exemplifies → cut
- enduring / lasting legacy, indelible mark, deeply rooted, rich history → cut
- underscores / highlights / emphasizes the importance of → cut
- reflects broader trends / contributes to the broader / setting the stage for → cut
- trailing "-ing" analysis: ", highlighting ..." ", underscoring ..." ", reflecting ..."
  ", showcasing ..." ", ensuring ..." ", fostering ..." ", contributing to ..." ", symbolizing ..."
  ", demonstrating ..." → delete the clause; the sentence before it was the content
- inanimate subject doing human analysis ("the data underscores", "the design reflects a
  commitment") → say who did what, or state the fact

Exotic-metaphor vocabulary
- delve / dive into / deep dive / unpack → discuss, look at, or the specific verb
- tapestry / landscape (abstract) / realm / sphere / fabric → the plain noun (field, market, set)
- testament / beacon / hallmark / cornerstone / embodiment → cut
- journey / embark / navigate / voyage / path (abstract) → the concrete process
- unlock / harness / leverage / elevate / empower / supercharge / amplify → use, raise, let
- game changer / revolutionary / groundbreaking / transformative / paradigm shift → the change
- seamless / cutting-edge / state-of-the-art / best-in-class / world-class → cut or the spec
- meticulous / meticulously / painstakingly / carefully crafted → cut
- vibrant / bustling / thriving / dynamic / rich (abstract) → cut
- intricate / multifaceted / nuanced (as filler) → cut, or say which facets
- commendable / invaluable / unparalleled / profound → cut
- boasts (meaning "has") / nestled / in the heart of / breathtaking / renowned → has, in, cut
- foster / cultivate / nurture (abstract) → build, grow, or the concrete verb
- synergy / ecosystem (where "team" or "set of tools" is meant) / plethora / myriad → plain
- quietly / genuinely / honestly / load-bearing / the real question is / cuts to the heart of
  (Claude-era) → cut

Vague authority
- Experts argue / Studies show / Research suggests / Industry reports / Observers have noted /
  Some critics argue / It is widely regarded / many believe → name the source, or state it as the
  author's claim, or drop
- sources identified X as associated with / in connection with / connected to → the actual relation
  ("was CEO of", "worked at")

Filler
- It's important to note / It's worth noting / It should be noted / Notably / Importantly /
  Interestingly / That being said / To put it simply / Needless to say → cut
- In order to → to; the fact that → cut; a wide range of → cut or the count
- in terms of / with regard to / when it comes to / in the world of → rephrase

### Density tier (see thresholds in SKILL.md §2)

- Em dash, especially spaced ` — ` pairs as parentheses → comma, parentheses, period, colon
- adjective, adjective, and adjective; X, Y, and Z; three bullets everywhere → vary count
- not only X but also Y / it's not X, it's Y / not just X — Y / X rather than Y → state Y
- Additionally / Furthermore / Moreover / Consequently / Overall / Importantly opening a
  paragraph → delete
- may / might / could / can / typically / often / tends to / potentially / arguably stacked on
  claims the author is sure of → assert
- significantly / effectively / truly / deeply / remarkably / fundamentally / incredibly → cut
- serves as / stands as / functions as / acts as / operates as / represents → is
- boasts / features / offers / maintains (for "has") → has
- refers to (in a lead, for "is") → is
- implementation of / utilization of / provision of / the use of → implement, use, give
- capable of X-ing → can X; is able to → can; in the process of → cut
- synonym carousel for one referent → repeat the noun
- bold on "key" phrases mid-sentence; **Term:** description lists → plain, or prose
- Title Case Headings → sentence case; Overview / Background / Conclusion / Key Points headings
  on short text → remove
- "Awards and recognition", "X and Y" section titles on short text → merge
- tables for two facts → a sentence
- Here's the thing / Here's the kicker / The best part? / The result? → the point
- Picture this / Imagine a world where / Think of it as a highway for data → cut unless the
  audience needs the analogy
- Not a bug. Not a feature. A flaw. / They could ... They could ... They could → one sentence
- from X to Y (non-comparable ends) → list the items
- whether you're a beginner or an expert / look no further / everything you need to know → cut
- overall, important, including, factors, help, ensure, across, within, particularly, various,
  numerous, various aspects → thin; most delete cleanly

### Plain targets (what human prose in the same genre uses more)

- is, has, there is, it has
- wrote (not authored), used (not utilized), moved (not relocated), tried (not attempted),
  died (not passed away), showed (not demonstrated), big (not significant)
- a definite statement: "is the only", "was the first", "one of the best"
- small qualifiers: very, perhaps, a bit, probably
- a number, a name, a date, a version, a filename
- an opinion the author holds; a risk named; a complaint

## Russian

Russian carries extra weight in two places: translationese (calqued English connectors) and
officialese that models apply to every genre. The long dash «—» is NOT a tell. High grammatical
correctness is NOT a tell. Technical terms are NOT a tell.

### Delete tier

Chat residue and disclaimers
- Конечно! / Безусловно! / Отличный вопрос / Вы абсолютно правы → cut
- Надеюсь, это помогло / было полезно / Дайте знать, если / Если хотите, могу / Сообщите мне →
  drop
- Вот (переработанный / улучшенный) вариант / Вот черновик → drop
- Как языковая модель / На момент моего обучения / По состоянию на [дата] (о знаниях модели) → drop
- По имеющимся данным / На момент написания / Конкретные детали ограничены / В доступных источниках
  → drop
- Важно помнить, что ... может варьироваться / Рекомендуется проконсультироваться → drop
- [Имя], [Дата], [Название компании], [Вставьте ...] → fill or drop

Debris: as in English, plus `&nbsp;`, `&thinsp;`, `&hellip;` and HTML `data-start`/`data-end`
attributes from a ChatGPT paste.

Meta-narration and scaffolding
- В этой статье мы рассмотрим / Сегодня мы поговорим о / Давайте разберёмся / Давайте погрузимся /
  Разберём по порядку → drop
- В заключение / Подводя итог / Резюмируя / В итоге / Таким образом (as a recap opener) / Вкратце /
  В целом (as a recap opener) → drop the recap
- Раздел «Заключение» / «Выводы», который повторяет текст → drop
- Будущее за ... / Перспективы на будущее / Несмотря на эти проблемы, X продолжает развиваться →
  drop
- Ключевые выводы / Основные моменты / TL;DR без запроса → drop

Grand openers
- В современном мире / В современном динамично развивающемся мире / В эпоху цифровизации /
  В условиях ... / Не секрет, что / Как известно / Сегодня всё больше людей → drop
- X — это Y, который ... (definition of the topic to someone who knows it) → drop

Importance puffery and significance tails
- играет ключевую / важную / значительную / решающую роль → определяет, или сам факт
- является ключевым аспектом / одним из ключевых факторов → cut
- знаковый момент / поворотный момент / неизгладимый след / вековое наследие → the event
- подчёркивает важность / значимость; выступает символом; служит напоминанием; отражает →
  cut
- «..., что подчёркивает ...», «..., что демонстрирует ...», «..., способствуя ...»,
  «..., обеспечивая ...», «..., подчёркивая ...», «..., отражая ...» → delete the tail
- факт или событие «подчёркивает», «демонстрирует», «отражает», «влияет», «содействует»
  (inanimate subject analysing) → who did what
- совершил революцию в / кардинально меняет / выводит на новый уровень → the concrete change

Exotic / inflated vocabulary
- многогранный / всеобъемлющий / комплексный (as filler) / уникальный / инновационный /
  прорывной / революционный → cut
- погрузиться в тему / раскрыть потенциал / открыть новые горизонты → the plain verb
- ландшафт (abstract) / экосистема (for «набор инструментов») / палитра / синергия / парадигма →
  plain noun
- путь / путешествие (abstract) / «в самом сердце» / «богатое культурное наследие» /
  «живописный» / «захватывающий дух» / «может похвастаться» → cut
- динамичный / яркий / богатый / разнообразный (abstract) → cut
- бесшовный / эффективный / качественный / надёжный / комплексный as bare praise → cut; with a
  number or a comparison after them they are domain words and stay
- поистине / безусловно / несомненно / крайне / существенно (unsupported) → cut

Vague authority
- Эксперты отмечают / Специалисты считают / Ряд исследований показал / Многие компании /
  По словам экспертов / Некоторые критики утверждают / Отраслевые отчёты → name it or drop
- связан с / ассоциируется с / имеет отношение к (for a concrete role) → the role

Filler
- Важно отметить / Стоит отметить / Следует отметить / Следует подчеркнуть / Необходимо
  подчеркнуть / Нельзя не отметить / Стоит учесть → cut
- Немаловажную роль играет / Не менее важно → cut
- в рамках (for «в», «при», «во время») → в, при
- данный (for «этот») → этот, or cut
- в целом / в том числе / в частности / в первую очередь (stacked) → thin
- с целью → чтобы; в связи с тем, что → потому что; для того чтобы → чтобы

### Density tier

- Тем не менее / Таким образом / Следовательно / Кроме того / Более того / Помимо этого / Также
  стоит отметить opening paragraphs → delete the connector
- Не только ..., но и ... / Это не просто ..., это ... / Не X, а Y / Дело не в ..., а в ... →
  state Y; once per text is fine
- Во-первых ... Во-вторых ... В-третьих ... everywhere; three adjectives; three bullets → vary
- является / представляет собой / выступает в качестве / осуществляет / обеспечивает /
  позволяет / способствует / направлен на / призван → plain predicate: «это», «даёт», «делает»
- осуществление / реализация / проведение / обеспечение / формирование / внедрение / использование
  (-ание/-ение/-ация chains) → the verb: запустили, проверили, внедрили
- было принято решение / была проведена работа / будет осуществлён (passive) → мы решили,
  команда сделала
- «методы, которые позволяют ..., идеи, которые помогают ...» → split, or a participle
- может стать / способен обеспечить / может повлиять / позволяет достичь (modal cluster on
  claims the author is sure of) → assert
- Представьте, что вы ... / Представьте мир, где ... / Это как ... → cut unless the audience
  needs the analogy
- И вот что интересно / Но есть нюанс / Самое интересное? (false suspense) → the point
- Короткие. Рубленые. Фразы. / Без воды, без эмоций, без лишних слов (anaphora) → one sentence
- от ... до ... with non-comparable ends → list
- Заголовки С Каждым Словом С Большой Буквы → only the first word capitalised
- **Термин:** описание lists; bold mid-sentence → plain, or prose
- маленькие таблицы на два факта → a sentence
- Абсолютно одинаковые абзацы по 3–4 предложения; каждый раздел «тезис → пояснение → вывод» →
  unequal paragraphs, no per-section conclusions

### Absence signals (restore only in casual, blog or chat register)

- No particles at all: же, ведь, вот, -то, мол → one or two where speech would have them
- No sentence starts with «А», «И», «Но» → allow some
- No professional slang, no idiom, no concrete price/city/version/tool → use what the source has
- Every sentence 15–20 words → one short sentence, one long one
- Not for official letters, specs, legal or academic text: there the native register is formal,
  and the fix is specificity and shape.

### Plain targets

- это, есть, у X есть, X делает
- написал (не «осуществил написание»), использовал (не «задействовал»), проверил, запустил, сломалось
- a definite statement: «единственный», «первый», «лучший из»
- small qualifiers: очень, пожалуй, скорее, немного
- a number, a name, a date, a version, a filename
- a position: «я бы не стал», «это плохо, потому что», «мне не нравится»
